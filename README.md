# MoMo Merchant Intelligence

MoMoMI is a fintech competition prototype exploring how digital money movements can become clearer business records and intelligence. The current dashboard uses synthetic local data only.

## Development

```sh
npm install
npm run dev
```

Run `npm run build` to check TypeScript and create a Vite production build.

There is no backend, production database, external AI API, or live MTN MoMo connection. See [AGENTS.md](./AGENTS.md) for prototype constraints, coding conventions, and fintech data-integrity rules.
